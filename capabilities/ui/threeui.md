# ThreeUI — Three.js Components & MCP

Source: https://threeui.com/
Category: UI / 3D Components

## What It Is
Open-source library of 160+ Three.js components, templates, and interactive shaders.

## Components Available
- **Hero Sections**: Complete Shelf, Predictive Arc, Tidecrest Terrain, Meridian Slow Matter, Mara Voss, Betawise Globe, Astral Atlas, Retro Metallic
- **3D Elements**: Sylva Living World, Structure Flow, Character Carousel, Country Towers, Brand Orbs
- **UI Elements**: Circle Buttons, Character Filmstrip
- **Backgrounds**: Predictive Arc variants, Tidecrest variants
- **Motion Design**: Understory Sting

## MCP Access
- URL: https://threeui.com/api/mcp
- Allows AI agents to browse, search, and integrate Three.js components

## Integration
- Use for AI System dashboard 3D UI enhancements
- Agent can pull hero sections and components via MCP
- Three.js-based animations for Live Office view
